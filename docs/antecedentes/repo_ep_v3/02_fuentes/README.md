## Reglas

- Una fuente secundaria no se eleva a HECHO cuando el dato requiere confirmación primaria.
- Las cifras de Arca Continental (grupo) no se usan como cifras de ACL Perú (F14).
- El 46 % de clientes sin TUALI es un cálculo del equipo (200 mil sobre 370 mil) y se marca como SUPUESTO; las dos bases no son iguales (clientes de ACL frente a bodegas del país).
